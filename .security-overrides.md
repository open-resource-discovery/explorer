# Security Overrides

Overrides in root `package.json` that force safe versions of transitive dependencies.
Each entry is removed automatically by the dep-sweep skill when `npm audit` is clean for that package.

## @ai-sdk/provider-utils (transitive via ai, @ai-sdk/gateway, @ai-sdk/vue)

- **Override**: `"@ai-sdk/provider-utils": "4.0.51"`
- **CVE**: CVE-2026-8769
- **GHSA**: GHSA-866g-f22w-33x8
- **Severity**: low
- **Summary**: Uncontrolled Resource Consumption in `@ai-sdk/provider-utils`; fixed in 4.0.33
- **Dependabot alert**: #6
- **Added**: 2026-09-09, bumped 4.0.50 → 4.0.51 on 2026-09-21 (Renovate PR #34)
- **Note**: `ai`/`@ai-sdk/gateway`/`@ai-sdk/vue` pin provider-utils to `4.0.5`. Pinned to `4.0.51` (head of the `ai-v6` / 4.0.x line, matching `ai@6.x`); clears the full low-severity cascade through `@ai-sdk/gateway`, `@ai-sdk/vue`, `ai`, and the `@scalar/*` → `@open-resource-discovery/metadata-renderer` chain. Renovate PR #38 proposes a `v5.0.45` major here — deliberately NOT taken: forcing the transitive to a major the parents were not built against risks runtime breakage in the scalar/api-reference chain that unit tests do not exercise. Left open for a maintainer to evaluate separately.
- **Remove when**: `npm audit` reports no advisories for `@ai-sdk/provider-utils` (when the `ai`/`@ai-sdk/*` packages upgrade their pinned provider-utils past 4.0.32)

## js-yaml (transitive via @asyncapi/parser)

- **Override**: `"js-yaml": "4.3.2"`
- **CVE**: CVE-2026-84375
- **GHSA**: GHSA-2883-xcg3-v3hh
- **Severity**: high
- **Summary**: `js-yaml`: `maxTotalMergeKeys` does not limit CPU use for empty merge sources; fixed in 4.3.2
- **Dependabot alert**: #7
- **Added**: 2026-09-21
- **Note**: `@asyncapi/parser` pins `js-yaml@4.3.1` (vulnerable range `>= 4.0.0, < 4.3.2`). Pinned to the exact first patched 4.x release `4.3.2` — an open `>=4.3.2` floor lets npm cross into `js-yaml@5.x`, a major with breaking API changes `@asyncapi/parser` was not built against. Only lock file affected is the root `package-lock.json`; `app/` and `auth-proxy/` do not depend on js-yaml.
- **Remove when**: `npm audit` reports no advisories for `js-yaml` (when `@asyncapi/parser` bumps its pinned js-yaml to ≥ 4.3.2)

## unhead (unfixable — upstream blocked)

- **CVE**: CVE-2026-39315 (also #18 CVE-2026-31873, #17 CVE-2026-31860)
- **GHSA**: GHSA-95h2-gj7x-gx9w
- **Severity**: medium
- **Summary**: Unhead vulnerabilities via `@open-resource-discovery/metadata-renderer` → `@scalar/api-reference-react` → `@unhead/vue@1.11.20` → `unhead@1.11.20`
- **Dependabot alerts**: #20, #18, #17
- **Status**: No fix available. `unhead` 2.x does not exist on npm (version jumped 1.x → 3.x). Forcing an override to 3.x would break `@unhead/vue@1.x` API compatibility. Fix requires `@open-resource-discovery/metadata-renderer` to upgrade its `@scalar` dependency chain.
- **Action**: Revisit when `@open-resource-discovery/metadata-renderer` releases an update.
