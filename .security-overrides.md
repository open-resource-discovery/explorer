# Security Overrides

Overrides in root `package.json` that force safe versions of transitive dependencies.
Each entry is removed automatically by the resolve-renovate skill when `npm audit` is clean for that package.

## dompurify

- **Override**: `"dompurify": "3.4.15"`
- **CVE**: N/A (alert #37 GHSA-55q2-fjhq-7xh7 — XSS via IN_PLACE hook removal)
- **GHSA**: GHSA-55q2-fjhq-7xh7
- **Severity**: medium
- **Summary**: DOMPurify IN_PLACE hook removal leaves a detached subtree executable, causing XSS; fixed in 3.4.13
- **Dependabot alerts**: #37 (also prior #15, #16 — all fixed)
- **Added**: prior run, updated 2026-08-10, bumped 3.4.13 → 3.4.14 on 2026-09-04, bumped 3.4.14 → 3.4.15 on 2026-09-07
- **Remove when**: `npm audit` reports no advisories for `dompurify` (currently needed by monaco-editor@0.56.0 which pins dompurify@3.4.8)

## fast-uri (transitive via ajv)

- **Override**: `"fast-uri": "3.1.7"`
- **CVE**: CVE-2026-76172, CVE-2026-75975, CVE-2026-75899, CVE-2026-75931
- **GHSA**: GHSA-jqff-g426-hqxp, GHSA-f65p-4m7j-42xc, GHSA-fph4-wmhf-6fwf, GHSA-5jgf-p345-68v8
- **Severity**: high (all four)
- **Summary**: Multiple SSRF and host confusion vulnerabilities via percent-encoded scheme normalization, malformed IPv6, repeated hostname percent-decoding, and IDN canonicalization; all fixed in 3.1.6
- **Dependabot alerts**: #2, #3, #4, #5
- **Added**: 2026-09-04, pinned to exact 3.1.7 on 2026-09-07
- **Note**: ajv@8.20.0 requires `^3.0.1`; override ensures the resolved version is at the safe floor; 3.1.7 is the latest 3.x release
- **Remove when**: `npm audit` reports no advisories for `fast-uri` (wait for ajv to upgrade its fast-uri dep past 3.1.5)

## unhead (unfixable — upstream blocked)

- **CVE**: CVE-2026-39315 (also #18 CVE-2026-31873, #17 CVE-2026-31860)
- **GHSA**: GHSA-95h2-gj7x-gx9w
- **Severity**: medium
- **Summary**: Unhead vulnerabilities via `@open-resource-discovery/metadata-renderer` → `@scalar/api-reference-react` → `@unhead/vue@1.11.20` → `unhead@1.11.20`
- **Dependabot alerts**: #20, #18, #17
- **Status**: No fix available. `unhead` 2.x does not exist on npm (version jumped 1.x → 3.x). Forcing an override to 3.x would break `@unhead/vue@1.x` API compatibility. Fix requires `@open-resource-discovery/metadata-renderer` to upgrade its `@scalar` dependency chain.
- **Action**: Revisit when `@open-resource-discovery/metadata-renderer` releases an update.
