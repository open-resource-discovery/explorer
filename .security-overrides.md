# Security Overrides

Overrides in root `package.json` that force safe versions of transitive dependencies.
Each entry is removed automatically by the dep-sweep skill when `npm audit` is clean for that package.

## @ai-sdk/provider-utils (transitive via ai, @ai-sdk/gateway, @ai-sdk/vue)

- **Override**: `"@ai-sdk/provider-utils": "4.0.62"`
- **CVE**: CVE-2026-8769
- **GHSA**: GHSA-866g-f22w-33x8
- **Severity**: low
- **Summary**: Uncontrolled Resource Consumption in `@ai-sdk/provider-utils`; fixed in 4.0.33
- **Dependabot alert**: #6
- **Added**: 2026-09-09, bumped 4.0.50 → 4.0.51 → 4.0.57 → 4.0.62 (latest 2026-11-16)
- **Note**: `ai`/`@ai-sdk/gateway`/`@ai-sdk/vue` pin provider-utils to `4.0.5`. Pinned to the head of the `4.0.x` line (matching `ai@6.x`); clears the full low-severity cascade through `@ai-sdk/gateway`, `@ai-sdk/vue`, `ai`, and the `@scalar/*` → `@open-resource-discovery/metadata-renderer` chain. A `v5.0.x` major has been proposed here before — deliberately NOT taken: forcing the transitive to a major the parents were not built against risks runtime breakage in the scalar/api-reference chain that unit tests do not exercise.
- **Remove when**: `npm audit` reports no advisories for `@ai-sdk/provider-utils` (when the `ai`/`@ai-sdk/*` packages upgrade their pinned provider-utils past 4.0.32)

## js-yaml (transitive via @asyncapi/parser)

- **Override**: `"js-yaml": "5.5.0"`
- **CVE**: CVE-2026-84375
- **GHSA**: GHSA-2883-xcg3-v3hh
- **Severity**: high
- **Summary**: `js-yaml`: `maxTotalMergeKeys` does not limit CPU use for empty merge sources; fixed in 4.3.2
- **Dependabot alert**: #7
- **Added**: 2026-09-21
- **Note**: Pins the single transitive `js-yaml` instance in the root tree to the head of the `5.x` line (`5.5.0`), well above the `< 4.3.2` vulnerable floor. The tree resolves cleanly against 5.x and unit tests pass; the consuming `@asyncapi/parser` chain does not exercise the removed 4.x APIs in this project. Only the root `package-lock.json` is affected; `app/` and `auth-proxy/` do not depend on js-yaml.
- **Remove when**: `npm audit` reports no advisories for `js-yaml` (when consumers resolve a safe version naturally).
